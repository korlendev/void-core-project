# VOIDCORE Project Pack v1.0

A 2D top-down, room-by-room survival roguelite design and production starter pack.

## Files
- `VOIDCORE_Project_Bible_v1.0.docx` — full GDD / production plan.
- `VOIDCORE_Project_Bible_v1.0.md` — editable Markdown copy.
- `VOIDCORE_Asset_Tracker_v1.0.xlsx` — asset tracker, dashboard, room plan and combat catalog.
- `VOIDCORE_Asset_Tracker_v1.0.csv` — portable asset checklist.
- `VOIDCORE_HUD_Wireframe.png` — HUD and minimap layout reference.
- `VOIDCORE_Room_Map_Example.png` — six-room route map example.

## Core rule
One room encounter = one wave. A floor contains connected room nodes. The player clears one room, chooses a reward, then chooses the next available connected room.

## Combat priority
1. Melee — primary damage and core play rhythm.
2. Firearm — secondary ranged pressure and finishing.
3. Magic — control, defense, mobility and burst.

## First playable target
One character, one zone, six rooms, three enemy archetypes, one elite variant, one boss, one melee weapon, one firearm, two magic skills, an in-room minimap and a floor route map.

## Naming
VOIDCORE is a working title and can be changed before implementation.

## Asset licensing
Before integrating any asset, record the original source URL, creator, license, attribution requirements and commercial-use permissions. Do not assume that an asset visible online is free to redistribute.
